VIDEO PATTERNS · 20種

動画構成パターン帳

引用ポスト用のテキスト動画を単調にしないための構図集です。投稿ごとに3〜5種類を組み合わせると、同じ見た目の連続を避けられます。各カードの「型名」を script.json の type に書けば、その構図で動画が書き出されます。

20パターンを順に再生する見本（横1920×1080・約97秒）。数字は見本用の架空のものです。

組み合わせの目安

冒頭は「つかみ」から1つ、本編は「比較・データ」「説明」から内容に合うものを2〜4つ、最後に「締め」を1つ。同じ型を続けて使わないのがコツです。

{ "type": "versus", "dur": 5, "tag": "比較", "a": { "label": "…", "value": "18円" }, "b": { … }, "win": "b" }
