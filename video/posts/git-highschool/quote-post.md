## 案A（言い切りから）おすすめ
GitHubは、知らずに使うと壊れる

でも、押す緑のボタンは3つだけ
押す前に見る場所は、1つだけ

①Compare & pull request（提出）
②Create pull request
③Merge pull request（合わせる）

見るのは「Files changed」
頼んだ行だけが緑なら、合格

手を動かすのはAI、見て押すのは自分

## 案B（安心させる型）
合わせたあとに間違いに気づいても、大丈夫

Revertを押すと
記録は消えない
「打ち消した」という記録が1つ増えるだけ

ただし、1つだけ戻せないものがある
✔一度上げたパスワードやAPIの鍵

上げる前に「.envを記録から外して」と1行送る

怖いのはGitじゃなく、見ずに押すこと
